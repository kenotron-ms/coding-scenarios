# URL Shortener — Solution README

## How to Run

```bash
pip install -r solution/requirements.txt
export PORT=8000
export URLSHORT_DB=/tmp/urlshort.db
python -m solution.main
```

Optional environment variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | *(required)* | TCP port to bind on `127.0.0.1` |
| `URLSHORT_DB` | *(required)* | Absolute path to the SQLite database file (created if absent) |
| `URLSHORT_SEED` | *(unset)* | Integer seed for the code-generation RNG (for reproducible tests) |
| `URLSHORT_BASE_URL` | *(unset)* | If set, `short_url` uses this as the URL prefix instead of deriving from the `Host` header |

The service binds `127.0.0.1:$PORT`, logs one JSON line per request to stdout, and exits cleanly on `SIGTERM`.

## Ambiguity Resolutions

### A-1 (Idempotency)

**Resolution: Idempotent / dedupe.**

POSTing the same URL twice returns the same code (HTTP 201 both times). Clicks are preserved and not reset. Deduplication keys on the verbatim stored URL — no normalization is applied before the lookup (consistent with A-3).

Rationale: A bot retrying a timed-out POST must not mint two codes for the same URL. If the first request committed but the response was lost in transit, the retry returns the existing code rather than creating a duplicate. This is the safe default for any caller that cannot distinguish "request lost" from "server error".

### A-2 (Code charset/length)

**Resolution: Fixed length 6, base62 alphabet `[0-9A-Za-z]`.**

- Alphabet: digits `0-9`, uppercase `A-Z`, lowercase `a-z` (62 characters total)
- Length: exactly 6 characters
- Regex: `^[0-9A-Za-z]{6}$`
- Codes are generated by drawing 6 random characters from this alphabet using a seeded `random.Random` instance.
- Reserved segments (`health`, `api`, `docs`, `redoc`, `openapi.json`, `favicon.ico`, and the empty string) are skipped and redrawn until a non-reserved code is produced.
- On UNIQUE constraint violation (collision), the service retries up to 10 times; if all attempts are exhausted it returns HTTP 500.

The base62 alphabet gives 62^6 = 56,800,235,584 possible codes, making collisions extremely rare in practice.

### A-3 (URL normalization)

**Resolution: Store verbatim — no normalization.**

URLs are stored exactly as submitted. No case-folding of the host, no stripping of default ports, no removal of fragments, no trailing-slash normalization. The `Location` header in 302 responses is byte-identical to the submitted URL. Under A-1, deduplication also keys on the verbatim URL — `https://example.com/a` and `https://example.com/a/` are treated as distinct URLs and receive distinct codes.
